# Мой день

Ежедневник для Android: дела, лекарства с громким сигналом, события, дни рождения, доходы и расходы, долги, погода и утренняя сводка.

## Возможности

- Напоминания на дату и время с повтором: один раз, каждый день, по дням недели, каждый месяц, каждый год, через N дней
- Лекарства: несколько приёмов в день, курс до определённой даты, громкий сигнал на весь экран с кнопками «Принял» и «Отложить»
- События с напоминанием заранее
- Дни рождения с напоминанием в день, за день, за 3 дня, за неделю
- Доходы и расходы по категориям, долги с частичными возвратами и напоминанием о сроке
- Погода (Open-Meteo, без ключей) и утренняя сводка в уведомлении
- 9 цветовых тем, 5 шрифтов, 4 размера текста
- Аккаунт по почте и паролю, синхронизация через Supabase
- Автообновление из релизов этого репозитория

## Как выпустить обновление

1. Увеличить `versionCode` и `versionName` в `app/build.gradle.kts`
2. Собрать: `gradle :app:assembleRelease` (нужен `keystore.properties` и ключ подписи, в репозиторий не входят)
3. Создать релиз с тегом `vX.Y.Z` и приложить APK. Приложение увидит его само.

Обновление ставится только поверх версии с той же подписью, поэтому ключ `moyden-release.jks` нужно хранить.
